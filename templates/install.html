🪟 Windows Background Agent

Open PowerShell as Administrator, paste the payload below, and press Enter to deploy the silent telemetry script. 

$dir = "$env:LOCALAPPDATA\Sentinel"; if (!(Test-Path $dir)) { New-Item -ItemType Directory -Path $dir | Out-Null }; $script = "$dir\tracker.ps1"; @'
$API_KEY = "{{ api_key }}"
$URL = "https://sentinel.barakaberenge.com/api/heartbeat"
$batt = Get-WmiObject -Class Win32_Battery -ErrorAction SilentlyContinue
$battery = if ($batt) { $batt.EstimatedChargeRemaining } else { 100 }
Add-Type -AssemblyName System.Device
$geo = New-Object System.Device.Location.GeoCoordinateWatcher
$geo.Start()
$watchTimeout = [System.Diagnostics.Stopwatch]::StartNew()
while (($geo.Status -ne 'Ready') -and ($watchTimeout.Elapsed.TotalSeconds -lt 5)) { Start-Sleep -Milliseconds 200 }
$loc = $geo.Position.Location
$lat = if ($loc.IsUnknown) { 0 } else { $loc.Latitude }
$lon = if ($loc.IsUnknown) { 0 } else { $loc.Longitude }
$payload = @{ latitude = $lat; longitude = $lon; battery_level = [int]$battery } | ConvertTo-Json
Invoke-RestMethod -Uri $URL -Method Post -Headers @{ "X-API-Key" = $API_KEY; "Content-Type" = "application/json" } -Body $payload
'@ | Set-Content -Path $script -Encoding UTF8; schtasks /create /tn "SentinelTelemetry" /tr "powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File \"$script\"" /sc minute /mo 5 /f; powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File "$script"; Write-Host "Sentinel Agent installed successfully." -ForegroundColor Green

🍏 Unix/Mac Cron Agent

Open Terminal, paste the script injection below, and execute to configure the automated cron job. 

mkdir -p ~/.sentinel && cat << 'EOF' > ~/.sentinel/tracker.sh
#!/bin/bash
LOC=$(curl -s https://ipinfo.io/json)
LAT=$(echo "$LOC" | grep -o '"loc": "[^"]*' | cut -d'"' -f4 | cut -d',' -f1)
LON=$(echo "$LOC" | grep -o '"loc": "[^"]*' | cut -d'"' -f4 | cut -d',' -f2)
BATT=$(pmset -g batt 2>/dev/null | grep -Eo "[0-9]+%" | tr -d '%' | head -1)
[ -z "$BATT" ] && BATT=$(cat /sys/class/power_supply/BAT*/capacity 2>/dev/null | head -1)
BATT=${BATT:-100}
curl -s -X POST https://sentinel.barakaberenge.com/api/heartbeat -H "X-API-Key: {{ api_key }}" -H "Content-Type: application/json" -d "{\"latitude\": ${LAT:-0}, \"longitude\": ${LON:-0}, \"battery_level\": $BATT}"
EOF
chmod +x ~/.sentinel/tracker.sh && (crontab -l 2>/dev/null | grep -v "tracker.sh"; echo "*/5 * * * * ~/.sentinel/tracker.sh >/dev/null 2>&1") | crontab - && ~/.sentinel/tracker.sh &
echo "Sentinel Cron Job active."
